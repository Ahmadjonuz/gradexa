1. UPDATE-GRADEXA-STUDY-FLOW.cjs faylini ishlayotgan gradexa papkasida

2. Shu papkaning manzil satriga cmd yozib Enter bosing. CMDda bajaring:
     node UPDATE-GRADEXA-STUDY-FLOW.cjs --check
     node UPDATE-GRADEXA-STUDY-FLOW.cjs
3. Birinchi buyruq fayllarni solishtiradi, yozmaydi. Ikkinchisi zaxira olib
   yangilaydi. “Fayllar ... farq qiladi” chiqsa, shu yerda to‘xtang.
   Majburlab ustidan yozmang; farq qilgan fayl nomlarini yuboring.
4. Tekshiruv:
     npm.cmd run typecheck
     npm.cmd run test:next
     npm.cmd run build:next
   Birortasi xato chiqarsa, keyingisini bajarmay xato matnini yuboring.
5. Avval ishlagan START-GRADEXA-BANK.cmd yoki START-GRADEXA.cmd orqali oching.

Yangi npm paket qo‘shilmadi: npm install / npm ci qayta kerak emas.

NIMALAR TUZATILDI
- /student: “Davom ettiring” faqat biriktirilgan nashr qilingan kursdan,
  mavjud position/module/id tartibiga mos ochiladigan darsni tanlaydi.
- /student, /student/profile, /admin/students/[studentId]: so‘nggi natijalar
  UUID bo‘yicha emas, haqiqiy sana bo‘yicha tartiblanadi; mikrosoniya saqlanadi.
- /student/quizzes va kurs sahifasi: urinishlar soni, nashr holati,
  kursga yozilish va profil faolligi bir xil qoidada tekshiriladi.
- Urinishlar tugagach, talaba saqlangan so‘nggi natijasiga o‘ta oladi.
- Bo‘sh savolli test sahifani yiqitmaydi, tushunarli xabar ko‘rsatadi.
- Testni yakunlashda tasdiqlash oynasi; yetishmagan javobga o‘tish.
- Sahifani yangilash/yopishda javoblar yo‘qolishi haqida brauzer ogohlantiradi.
  Test ichidagi “Testlar ro‘yxati” havolasi ham chiqishni tasdiqlatadi.
  Yon menyu va brauzer Back uchun universal route-blocker qo‘shilmagan.
- Yuborish natijasi kelmasa, ayni javoblar va requestId bilan qayta
  tekshiriladi. Mavjud server idempotency qoidasi takroriy urinishni to‘sadi.
  Bu javoblar bazaga yozilgani tasdiqlangan degani emas; natijani tekshiring.
- Administrator testni tahrirlasa, yangilangan ma’lumot kelganda talaba
  ogohlantiriladi; eski savollar yuborilmaydi. Server revision tekshiruvi qoladi.
- /student/results va /admin/quiz-results: 10 tadan sahifalash, kombinatsiyali
  filtrlar, barcha filtrlangan qatorlarni CSVga chiqarish (faqat joriy sahifa emas).
- Talaba natijalari ?quiz=... havolasi orqali filtrlanadi.
- Kursdan chiqarilgan talaba eski natijani ko‘radi, lekin qayta topshirish
  tugmasi chiqmaydi. Mavjud bo‘lmagan/arxivlangan kurs havolasi ro‘yxatga qaytadi.
- /admin kurs yakunlash filtrida faqat dastlabki 3 emas, barcha nashrdagi kurslar.
  Joriy kurslar jadvali avvalgidek 3 ta yozuv va “Barchasi” havolasini saqlaydi.
- /admin/analytics kunlik va soatlik guruhlash Toshkent vaqtida; natija sana
  filtri bilan bir xil. Kurs faolligi taklif qoralamalarini hisoblamaydi.
- Namuna hisobot saqlangan, aniq belgilangan. Undan soxta kurs yo‘liga o‘tilmaydi.
- Natijalardagi eski “brauzerda saqlanadi” yozuvi Supabase deb to‘g‘rilangan.
