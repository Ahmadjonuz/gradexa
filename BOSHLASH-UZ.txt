3. TO‘LIQ O‘RNATISH
Oddiy internetda: INSTALL-UZ.cmd
Bank proksisida: INSTALL-GRADEXA-BANK.cmd

Bank fayli 172.23.11.101:2002 proksini faqat o‘sha terminal jarayonida yoqadi.
Windows yoki npm proksi sozlamasini doimiy o‘zgartirmaydi.

Installer .env.localni birinchi marta yaratib Notepadda ochadi. Quyidagi
to‘rtta qiymatni o‘zingizning mavjud Gradexa Supabase loyihangizdan kiriting:

NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
NEXT_PUBLIC_SITE_URL=http://localhost:3000
SUPABASE_SECRET_KEY=

SUPABASE_SECRET_KEY faqat serverda ishlaydi va admin taklif yuborishi uchun
kerak. Unga NEXT_PUBLIC_ prefiksini qo‘shmang. Hech bir kalitni chatga yubormang.
Installer mavjud .env.local faylini almashtirmaydi va qiymatlarni terminalga
chiqarmaydi.

Installer ketma-ket npm kutubxonalarini o‘rnatadi, Supabase aloqasini tekshiradi,
production build, TypeScript va barcha avtomatik testlarni bajaradi. Oxirida:

TOLIQ ORNATISH MUVAFFAQIYATLI TUGADI

yozuvi chiqishi kerak.

4. SUPABASE SQL
Agar aynan shu Supabase loyihasida oldingi yangilanishlarni allaqachon bajargan
bo‘lsangiz, boshqa kompyuterga o‘tishda SQLni qayta bajarish shart emas.

Baza eski holatda bo‘lsa, quyidagi tartibda mavjud Supabase SQL Editor’da Run:
1) GRADEXA-DATA-UPDATE.sql
2) GRADEXA-INVITATIONS-UPDATE.sql

Foundation mavjud bazada 202609100001_gradexa_foundation.sql faylini qayta
bajarmang. Mutlaqo yangi Supabase loyihasi bo‘lsa supabase/README-UZ.mdni o‘qing.

Talaba taklif emaili uchun GRADEXA-INVITATIONS-UZ.txtdagi bir martalik Auth URL,
Invite user email template va Custom SMTP sozlamalarini bajaring. Tayyor HTML:
GRADEXA-INVITE-EMAIL.html.
