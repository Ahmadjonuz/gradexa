GRADEXA V2 — ADMIN, FORMALAR VA TIKLANISH YANGILANISHI
2026-10-07

Bu yangi loyiha emas. Avval o‘rnatilgan STUDY-FLOW yangilanishidan keyingi paket.
Supabase, login, rollar, RLS, takliflar va mavjud ma’lumotlar almashtirilmaydi.
SQL ishlatmang. Kutubxonalar o‘zgarmagan: npm install qayta kerak emas.

O‘RNATISH (Windows, bitta mavjud gradexa papkasiga)
1. Ishlab turgan server oynasida Ctrl+C bosing.
2. UPDATE-GRADEXA-ADMIN-FINISH.cjs faylini package.json yoniga joylang.
3. Shu papkada CMD oching va bajaring:
   node UPDATE-GRADEXA-ADMIN-FINISH.cjs --check
   Tekshiruv xatosiz bo‘lsa:
   node UPDATE-GRADEXA-ADMIN-FINISH.cjs
4. Har biri xatosiz tugagach keyingisini bajaring:
   npm.cmd run typecheck
   npm.cmd run test:next
   npm.cmd run build:next
5. Oldin ishlagan START-GRADEXA-BANK.cmd yoki START-GRADEXA.cmd orqali oching.
   Proksi kerak bo‘lmasa: npm.cmd run dev:next

Yangilagich barcha mosliklarni yozishdan OLDIN tekshiradi. Siz o‘zgartirgan
fayl farq qilsa, hech birini almashtirmaydi. Xato chiqsa, majburlamang:
fayllar ro‘yxatini yuboring. .env, node_modules va SQLga tegmaydi.
Avtomatik zaxira: gradexa-backups/admin-finish-<sana-vaqt>.
Qaytarish: serverni to‘xtatib, terminal ko‘rsatgan aniq zaxira yo‘li bilan:
node UPDATE-GRADEXA-ADMIN-FINISH.cjs --restore gradexa-backups/admin-finish-<aniq-nom>
Bu faqat loyiha fayllarini qaytaradi; bazadagi yozuvlarni o‘chirmaydi.
Qaytargandan so‘ng build:next ni qayta bajaring.

STORAGE / DATABASE HISOBOTI
Kurslar, darslar, testlar, talabalar, profil, qayd va sozlamalar:
oldin — mavjud Supabase; keyin — aynan o‘sha Supabase.
Bu paket yangi SELECT/INSERT/UPDATE/DELETE mexanizmini qo‘shmaydi.
Mavjud saveCourse, saveLesson, saveWorkspace va server actionlar qayta ishlatiladi.
Jadvallar: courses, lessons, profiles, enrollments, quizzes, quiz_questions,

WINDOWSDA YAKUNIY QABUL SINOVI
1. Admin: Ctrl+K orqali haqiqiy kurs, dars va testni topib oching.
   Qo‘ng‘iroq -> Takliflarni ko‘rish: taklif tabida ochilishi kerak.
2. /admin/lessons: yangi darsni saqlang, tahrirlang, yangilang va qayta oching.
   Bitta kurs/modulda bir xil tartib kiritsangiz tushunarli xabar chiqsin.
   Qoralama/Nashr filtri va sahifalashni tekshiring.
3. /admin/quizzes/new va mavjud test: savol, to‘g‘ri javob, nashr holatini
   saqlang. Saqlanmagan o‘zgarish bilan “Testlarga qaytish”ni bosing:
   tasdiqlash chiqsin. Saqlangan test studentda to‘g‘ri ko‘rinsin.
4. Student: profilingizni saqlang — yon menyu ismi/rasmi yangilansin.
   Ketma-ket kursdagi yopiq dars qidiruvdan kurs dasturini ochsin.
   Darsni yakunlang, test topshiring, natijani sahifa yangilab tekshiring.
5. Telefon/kichik oynada menyu, forma va jadvallarni tekshiring.
